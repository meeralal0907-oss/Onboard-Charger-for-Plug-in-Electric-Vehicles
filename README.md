# Onboard-Charger-for-Plug-in-Electric-Vehicles
Designed and simulated a two-stage onboard charger for plug-in electric vehicles using Bridgeless Interleaved Boost PFC and Phase-Shifted Full-Bridge (PSFB) converters. Focused on power factor correction, Zero Voltage Switching (ZVS), galvanic isolation, MATLAB/Simulink modelling and hardware prototyping with Arduino-based PWM control.
